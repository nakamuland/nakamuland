# Freenove ESP32-WROVER CAM タイムラプスカメラ

Freenove ESP32-WROVER CAM ボードに、SPI接続の外付け microSD モジュールを組み合わせて作る、単体動作のタイムラプスカメラです。

Wi-Fi ルーター不要。電源を入れると画角確認用のアクセスポイントが開き、ブラウザで撮影間隔と総枚数を設定すると、あとは「撮影 → microSD へ保存 → ディープスリープ」を繰り返します。

## 特徴

- **画角プレビュー**：電源投入／RST 時のみ 3 分間 Wi-Fi AP `TimelapseCam` を開き、`http://192.168.4.1` で静止画プレビュー（約1〜2秒更新）を確認できる
- **ブラウザで設定**：プレビュー画面のフォームで撮影間隔（秒）と総枚数（0 = 無制限）を設定。撮影時間の目安（間隔 × 枚数）もその場で表示される。設定は NVS に保存される
- **ディープスリープ運用**：タイマー起床時はプレビューをスキップして即撮影。総枚数に到達したら LED を3回点滅して完全停止
- **連番保存**：`/IMG00001.JPG` 形式で microSD へ保存。連番は NVS 管理なので電源を抜いても続きから
- **失敗時は止まって知らせる**：SD／カメラの初期化に失敗したらスリープせず、LED 点滅とシリアル出力（`[ERROR]`）で停止する

## ハードウェア

| 部品 | 内容 |
|---|---|
| カメラボード | Freenove ESP32-WROVER CAM（ESP32-WROVER-E + OV2640 2MP、PSRAM 4MB、microSD スロットなし） |
| SDモジュール | SPI接続の microSD（TF）モジュール（6ピン：3v3 / CS / MOSI / CLK / MISO / GND） |
| microSD カード | FAT32 フォーマット、32GB 以下推奨（exFAT 不可） |
| 電源 | USB 給電（microUSB） |

## 配線

| SDモジュール | Freenove ESP32-WROVER CAM |
|---|---|
| 3v3 | 3V3 |
| CS | GPIO32 |
| MOSI | GPIO13 |
| CLK | GPIO14 |
| MISO | GPIO33 |
| GND | GND |

配線のポイント：

- **電源は必ず 3.3V。** 同種モジュールの商品画像には「4.5V〜5.5V」と書かれていることがあるが、使用モジュールの裏面シルクは電源ピンが「3v3」。ESP32 の GPIO は 5V 耐性がないので、5V 給電・5V 信号は厳禁。
- **MISO に GPIO12 を使わない。** GPIO12 は起動時のストラップピンで、SD モジュールのプルアップで HIGH になるとフラッシュ電圧判定が狂い、起動失敗の原因になるため GPIO33 へ逃がしている。CS もストラップピンの GPIO15 を避けて GPIO32。
- カメラ使用ピン（GPIO 4 / 5 / 18 / 19 / 21 / 22 / 23 / 25 / 26 / 27 / 34 / 35 / 36 / 39）とは一切重ならない割り当てにしてある。
- SD の SPI 速度はジャンパ線での安定優先で 4MHz。

## Arduino IDE 設定

- ボード：**ESP32 Wrover Module**
- Partition Scheme：**Huge APP (3MB No OTA)**
- PSRAM：Enabled
- ポート：CH340 の COM ポート
- スケッチ：`freenove_timelapse_v03/freenove_timelapse_v03.ino`

## 使い方

1. スケッチを書き込んで USB 給電する
2. 最初の3分間、スマホで Wi-Fi `TimelapseCam`（パスワードはスケッチ内 `AP_PASS`）に接続する ※「インターネット未接続」と出ても接続を維持する
3. ブラウザで `http://192.168.4.1` を開き、画角を合わせて、撮影間隔と総枚数を入れて「この設定で撮影開始」を押す（押さずに3分経つと前回設定で自動開始）
4. あとは置いておくだけ。撮影のたびに基板の IO2 LED が一瞬点く
5. 終わったら microSD を PC で読み、連番 JPEG を取り出す

### 撮影時間の例

| 間隔 | 枚数 | 撮影時間 | 用途の目安 |
|---|---|---|---|
| 5秒 | 720枚 | 1時間 | 作業・工作の記録 |
| 10秒 | 360枚 | 1時間 | 3Dプリント見張り |
| 60秒 | 1,440枚 | 24時間 | 植物・天気・一日の記録 |
| 300秒 | 288枚 | 24時間 | ゆっくりした変化 |

容量目安：UXGA（1600×1200）で1枚約200〜400KB。1,440枚で約300〜600MB。

### 動画化

SD の画像を PC にコピーして ffmpeg で：

```
ffmpeg -framerate 24 -i IMG%05d.JPG -c:v libx264 -pix_fmt yuv420p timelapse.mp4
```

### 動作確認（シリアルモニタ 115200）

- `SD OK: ... MB` → SD 認識 OK
- `Saved /IMG00001.JPG (... bytes)` → 撮影・保存 OK
- `Sleeping for 60 sec... (shot 1/360 done)` → 進捗表示
- `Finished: 360 shots.` → 総枚数に到達して停止

## 注意・割り切り

- 時刻情報はない（RTC なし）。ファイル名は連番のみ
- プレビューはスムーズな動画ではなく静止画の連続更新（画角合わせ用）
- ディープスリープ中も基板の LED・CH340・レギュレータが電力を消費するため、バッテリー運用は「数日」オーダーの想定。モバイルバッテリーは低電流で自動停止する機種があるので、長時間運用は USB アダプタ給電が無難
- 途中で電源を抜くと、その回の進捗（○枚目まで）はリセットされる。ファイルは連番が続くので上書きはしない
